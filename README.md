# Staco Finance — Nuxt 4 rebuild

Nuxt 4 + Tailwind 4 (via `@tailwindcss/vite`). Tailwind config lives in
`app/assets/css/main.css` under `@theme` — there is no `tailwind.config.js`
in Tailwind 4.

```bash
npm install
npm run dev      # http://localhost:3000
```

- `/`      the landing page
- `/tabs`  test harness for the TabBar component

See `DECISIONS.md`.
